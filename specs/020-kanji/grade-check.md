# 配当表・読みの照らし合わせ（2026-10-30）

1〜3回目の漢字（90字）を、文部科学省の公式の表と照らし合わせた記録。

## 使った表

- 学年別漢字配当表: [小学校学習指導要領 第2章 第1節 国語 別表](https://www.mext.go.jp/a_menu/shotou/cs/1320015.htm)
- 音訓の割り振り: [音訓の小・中・高等学校段階別割り振り表（平成29年3月）](https://www.mext.go.jp/a_menu/shotou/new-cs/__icsFiles/afieldfile/2017/05/15/1385768.pdf)（PDF）
  - 漢字の横に、今の学習指導要領（平成29年告示）で配当されている学年が書いてある。ここから読み取った第三学年の字は200字で、上の配当表の第三学年と同じ（1〜3年は改訂で変わっていない）

## 結果

- **配当表**: 90字すべて 小3 の字。回をまたいだ重なりも無い
- 子供に見せる正解（読みの例文・書きの例文・ことばの正しい答え）の中の漢字は、すべて 小1〜小3 の字。まちがいの選択肢には 小4 以上の字もある（形が にている字を わざと入れている）
- **読み**: 読み・書き・ことばで使っている読みは、1つを除いて 小学校に割り振られた読み（送りがな・にごる音・つまる音は 手で確かめた）
  - **守 の ことば「こもり（子守）」**: 「もり」は 中学校に割り振られた読み。保護者と相談して「みまもる（見守る）」に かえる（`fix/kanji-mimamoru`）
