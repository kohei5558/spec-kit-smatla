# Feature Specification: 国語（漢字）

**Feature Branch**: `feature/020-kanji`
**Created**: 2026年10月27日
**Status**: Implemented（1回目：小3の30字）
**Input**: User description: "smart learning なので算数だけでなく、子どもが練習したい国語（漢字）を入れる"

## Clarifications

### Session 2026-10-27

- Q: 最初に足す教科は？ → A: 国語（漢字）。子どもが練習したいから
- Q: 問題の形は？ → A: 読み（漢字 → ひらがな）、書き（ひらがな → 漢字）、ことば（熟語）
- Q: 答え方は？ → A: 読みは ひらがなを入力（画面の 50音ボタン）。書き・ことばは 4つの中から選ぶ
- Q: 範囲は？ → A: 小1〜小3（440字）
- Q: 出し方は？ → A: 算数と同じく、正解して レベルが上がると 新しい漢字が出る
- Q: 進め方は？ → A: 中身（読み・例文・ことば・まぎらわしい漢字）は保護者が一覧で確認してから入れる。まず「仕組み ＋ 小3の最初の30字」で動かし、使ってから広げる

## 問題の形（例は [kanji-batch1.md](./kanji-batch1.md)）

| 種類 | 画面 | 答え |
|---|---|---|
| 読み | 「てんきが **悪**い。」**悪** の 読みは？ | 50音ボタンで「わる」と入力 |
| 書き | 「ちょうしが **わる**い。」**わる** を 漢字で 書くと？ | 悪・思・意・急 から選ぶ |
| ことば | 「あんしん」を 漢字で 書くと？ | 安心・字心・守心・安必 から選ぶ |

- 例文は ひらがな中心。漢字は 問題の字と 小1・小2 の字だけ（小3の ほかの字を まだ習っていないことがあるため）
- まちがえた選択肢は、形の にている漢字にする。本当にある ことばは まちがいの選択肢にしない
- 解説（019）: 読みは「悪い（わるい）」、書き・ことばは「正しい字と、まちがえた字の ちがい」を出す（あとで一覧を作って確認）

## 範囲とレベル（案）

- 漢字は 学年別漢字配当表（文部科学省）の 小1（80字）・小2（160字）・小3（200字）
- むずかしさ 1〜3: 小1、4〜6: 小2、7〜10: 小3（学年の中は配当表の順に分ける）
- 新しい種類なので レベル1（小1）から始まる（014 のルール）。小3には すぐ物足りなくなるので、四則と同じく 学年でスタートするかは 使ってみて決める
- 最初の段階は 小3の30字だけなので、全部のむずかしさで その30字を出す

## 仕組み（設計メモ、くわしくは plan.md）

- 「教科」を足す（算数・国語）。ホームで 教科を選んでから 種類を選ぶ
- 答えが数でない問題（文字・選択肢）を持てるようにする（DB の形が変わる。マイグレーションは SQLite・PostgreSQL の両方）
- 判定・学習記録・解説・学習結果・保護者の統計を、文字の答えでも動くようにする
- デイリーチャレンジは今までどおり 算数だけ

## Success Criteria _(mandatory)_

- **SC-001**: 子どもが 国語を選び、読み・書き・ことばを 解ける
- **SC-002**: 問題は 保護者が確認した一覧の中身だけで作られる（テストで確かめる）
- **SC-003**: 算数の問題・学習記録・画面は 変わらない
