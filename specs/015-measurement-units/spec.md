# Feature Specification: 長さ・重さ・かさ（単位）

**Feature Branch**: `feature/015-measurement-units`
**Created**: 2026年10月26日
**Status**: Implemented
**Input**: User description: "長さ・重さの単位を練習できるようにする（四則演算以外のカテゴリの2つ目）"

## 背景

小3で習う長さ（km）・重さ（g・kg・t）と、小2で習った長さ（mm・cm・m）・かさ（mL・dL・L）の単位は練習できない。013（時こくと時間）で作った「答えの形」（欄の数と単位）と、014 の種類ごとのレベルを使って足す。

## Clarifications

### Session 2026-10-26

- Q: どの単位を入れるか？ → A: 長さ（mm・cm・m・km）、重さ（g・kg・t）、かさ（mL・dL・L）のすべて
- Q: 問題の種類は？ → A: 単位のなおし方（1km200m は何m？など）と、単位のたし算・ひき算（1km300m + 800m は何km何m？など）
- Q: 扱いは？ → A: 時こくと同じ。新しい種類「長さ・重さ・かさ」としてレベル1から始め、デイリーチャレンジには出さない

## 単位の関係

| 種類 | 関係 |
|---|---|
| 長さ | 1cm = 10mm、1m = 100cm、1km = 1000m |
| 重さ | 1kg = 1000g、1t = 1000kg |
| かさ | 1L = 10dL、1dL = 100mL、1L = 1000mL |

## 難易度表（長さ・重さ・かさ）

| 難易度 | 内容 | 例 | 答えの欄 |
|---|---|---|---|
| 1 | 10倍・100倍の単位を小さい単位に（ちょうど） | 3cm は 何mm？ → 30、2m は 何cm？ → 200、4L は 何dL？ → 40 | [ ]mm |
| 2 | 10倍・100倍の単位を合わせて小さい単位に | 4cm5mm は 何mm？ → 45、1m30cm は 何cm？ → 130 | [ ]mm |
| 3 | 小さい単位を大きい単位と小さい単位に（10倍・100倍） | 45mm は 何cm何mm？ → 4cm5mm、260cm は 何m何cm？ → 2m60cm | [ ]cm[ ]mm |
| 4 | 1000倍の単位を小さい単位に（ちょうど） | 2km は 何m？ → 2000、3kg は 何g？ → 3000、2t は 何kg？ → 2000 | [ ]m |
| 5 | 1000倍の単位を合わせて小さい単位に | 1km200m は 何m？ → 1200、3kg50g は 何g？ → 3050 | [ ]m |
| 6 | 小さい単位を大きい単位と小さい単位に（1000倍） | 1250m は 何km何m？ → 1km250m、2080g は 何kg何g？ → 2kg80g | [ ]km[ ]m |
| 7 | たし算（くり上がりなし） | 1km300m + 400m は 何km何m？ → 1km700m、1L2dL + 3dL は 何L何dL？ → 1L5dL | [ ]km[ ]m |
| 8 | たし算（くり上がりあり） | 1km700m + 500m は 何km何m？ → 2km200m、2kg800g + 400g → 3kg200g | [ ]km[ ]m |
| 9 | ひき算（くり下がりなし） | 2km800m − 300m は 何km何m？ → 2km500m | [ ]km[ ]m |
| 10 | ひき算（くり下がりあり） | 2km − 400m は 何km何m？ → 1km600m、3kg200g − 500g → 2kg700g | [ ]km[ ]m |

- 難易度1〜3は 10倍・100倍の関係（mm・cm・m、dL・L、mL・dL）、4〜10は 1000倍の関係（m・km、g・kg、kg・t、mL・L）も使う。難易度7〜10は 10倍・100倍の組（cm と mm、L と dL など）も混ぜる
- 答えの大きい単位は 1〜9、小さい単位は 0 から（その単位の1つ上の数）未満。答えの小さい単位が 0 のときは 0 と入力する（例: 2km0m）
- 問題文では、0 の部分は書かない（「2km」と書き「2km0m」とは書かない）
- 各難易度30問。出題の難易度は、この種類のレベルで決まる（014。学年に関係なくレベル1から）

## User Scenarios & Testing _(mandatory)_

### User Story 1 - 長さ・重さ・かさを選んで練習する (Priority: P1)

子供はホーム画面で「長さ・重さ・かさ」を選び、問題に合った欄（[ ]m や [ ]km[ ]m）に答える。全部の欄が合っていれば正解になる。

**Why this priority**: 本機能の目的そのもの。

**Independent Test**: 子供でログインし、「長さ・重さ・かさ」を選んで問題を解き、全部の欄が合っているときだけ正解になることを確認する。

**Acceptance Scenarios**:

1. **Given** 子供がホーム画面を開いている、**When** 計算の種類を見る、**Then** 「長さ・重さ・かさ」が選べ、レベル1と出る
2. **Given** 「1250m は 何km何m？」の問題、**When** 問題画面を開く、**Then** 「km」「m」の2つの欄が表示される
3. **Given** 同じ問題で、**When** 1・250 と答える、**Then** 正解になりポイントがもらえる
4. **Given** 同じ問題で、**When** 1・25 や 12・50 と答える、**Then** 不正解になり「こたえは 1km250m」と表示される
5. **Given** 「3kg50g は 何g？」の問題、**When** 問題画面を開く、**Then** 「g」の欄1つが表示される
6. **Given** 計算の種類で「すべて」を選んだ、**When** 問題を解き続ける、**Then** 長さ・重さ・かさの問題も出ることがある

---

### User Story 2 - 学習結果で別に集計される (Priority: P2)

学習結果画面と保護者の統計で、「長さ・重さ・かさ」が他の種類と別に集計され、答えが単位つきで表示される。

**Why this priority**: 苦手な単元を見つけるため。US1 がないと意味がないため P2。

**Independent Test**: 数問解き、学習結果の種類別の集計と学習記録の一覧を確認する。

**Acceptance Scenarios**:

1. **Given** 長さ・重さ・かさを解いた、**When** 学習結果画面を開く、**Then** 種類別の集計とタブに「長さ・重さ・かさ」が出る
2. **Given** 学習記録の一覧で、**When** 記録を見る、**Then** 子供の答えと正解が「1km250m」「3050g」のように単位つきで表示される

### Edge Cases

- 欄を1つでも空欄のまま答える → 答えるボタンを押せない
- 小さい単位の欄に「1つ上の数」以上を入れる（例: 1km1250m） → 不正解（単位をなおす練習のため）
- デイリーチャレンジには選ばない
- 公開済みの DB にも、次の起動で問題が追加される（011）。既存の問題・学習記録は変わらない
- 新しい種類は計算の種類の**末尾**に足す

## Requirements _(mandatory)_

### Functional Requirements

- **FR-001**: 計算の種類に「長さ・重さ・かさ」を追加しなければならない
- **FR-002**: 問題は答えの欄の単位（1つまたは2つ）を持ち、画面はそれに合わせて欄と単位を表示しなければならない
- **FR-003**: 2つの欄がある問題は、両方が正しいときだけ正解としなければならない（013 と同じ仕組み）
- **FR-004**: 回答結果と学習記録は、正解・子供の答えを単位つきで表示できる情報を返さなければならない
- **FR-005**: 問題は難易度表に従って作らなければならない
- **FR-006**: デイリーチャレンジの問題には選んではならない
- **FR-007**: 計算の種類を表示するすべての画面で「長さ・重さ・かさ」を日本語で表示しなければならない

### Key Entities

- **CalculationType**: `Measurement = 6`（長さ・重さ・かさ）を末尾に追加
- **AnswerFormat**: 単位を問題ごとに持つ形を追加し、欄の単位（例: "km m"）を問題に持つ（詳細は tasks.md）

## Success Criteria _(mandatory)_

### Measurable Outcomes

- **SC-001**: 子供は「長さ・重さ・かさ」を選び、問題に合った欄に答えられる
- **SC-002**: 欄のどれか1つでも違えば必ず不正解になる
- **SC-003**: 全問題が難易度表の条件（単位の関係、答えの範囲、くり上がり・くり下がりの有無、正解が正しいこと）を満たすことを自動テストで確認できる
- **SC-004**: 既存の問題・学習記録・画面の表示は変わらない
