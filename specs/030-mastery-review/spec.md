# Feature Specification: マスターした問題は出さない・まちがえた問題を復習する

**Feature Branch**: `feature/030-mastery-review`
**Created**: 2026年11月25日
**Status**: Implemented
**Input**: 漢字のレベル10で 同じ問題が くり返し出て、覚えた答えで ポイントを かせげてしまった（保護者から）

## きっかけ

- 正解すると いつも 10ポイント。同じ問題でも 何回でも もらえる
- 漢字のレベル10は むずかしさ10（20字・54問）だけから出るので、同じ問題が すぐ もどってくる（画面が よけるのは 最近の10問だけ）
- 算数も しくみは同じ（問題の数が多いので 目立たないだけ）

## 決めたこと（保護者と相談済み）

1. **マスター**: 同じ問題を **3回つづけて 正解**したら「マスター」。マスターした問題は もう出さない
   - 「つづけて」は、その問題の 学習記録の 新しい方から3つが 全部 正解のこと。まちがえたら 数えなおし
   - 漢字も算数も、すべての種類で同じ（デイリーチャレンジは 1日1回なので 変えない）
2. **復習**: まちがえたままの問題（その問題の いちばん新しい 学習記録が 不正解）を、ふつうの問題に まぜて出す
   - だいたい **3問に1問**。選んだ種類（「すべて」なら その教科の種類）の中から。むずかしさは 問わない
   - 正解すれば「まちがえたまま」では なくなる（3回つづけて正解すれば マスター）
3. **その むずかしさを 全部マスターしたとき**: 下の むずかしさの、まだマスターしていない問題から出す。下も 全部マスターなら 上の むずかしさから出す
4. **その種類を 全部マスターしたとき**: 「すべて」なら ほかの種類から出す。種類を えらんでいたら、画面に 次の文を出して、ホームに もどれるようにする
5. もう かせいだ ポイントは そのまま

## 画面に出す文（確認してほしいところ）

- 種類を 全部マスターしたとき:
  - 「すごい！ ◯◯は ぜんぶ マスターしたよ！ ほかの もんだいにも チャレンジしてみよう」
  - （◯◯ は 種類の名前。例: 「かんじの よみ」「たしざん」）
- 復習の問題のとき、問題の上に 小さく: 「まえに まちがえた もんだい だよ」

## 決めていないこと・注意

- マスターの判定は 学習記録から その場で 数える（DB に 新しい列は 足さない）。記録が多くなっても 1人分なので 重くならない見込み
- 時こくの むずかしさ1（3問）のように 問題が少ないところは、すぐ全部マスターになり 上の むずかしさに 進む
- 問題の作り方を変えて 問題が入れかわったとき（011）は、新しい問題は マスターしていない あつかい
