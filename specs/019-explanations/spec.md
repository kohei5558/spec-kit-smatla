# Feature Specification: まちがえたときの解説

**Feature Branch**: `feature/019-explanations`
**Created**: 2026年10月27日
**Status**: Implemented
**Input**: User description: "不正解の場合は解説が欲しい"

## 背景

まちがえたときは「こたえは ○○」しか出ず、なぜそうなるかが分からない。考え方を短く見せ、よくある まちがいには一言そえる。

## Clarifications

### Session 2026-10-27

- Q: くわしさは？ → A: 式と考え方を短く（2〜3行）。1けたずつの手順はやらない
- Q: どこで間違えたかも出す？ → A: よくある まちがいだけ。計算で確実に見分けられるときだけ出し、当てはまらないときは出さない
- Q: 範囲は？ → A: 全部の種類（四則・あまり・時こく・単位・文章問題）
- Q: 文の確認は？ → A: 先に一覧（[explanations.md](./explanations.md)）を保護者が確認。確認済み（2026-10-27）。小さい問題（3 + 4、7 − 3 など）は式だけ

## User Scenarios & Testing _(mandatory)_

### User Story 1 - まちがえたら考え方が出る (Priority: P1)

**Acceptance Scenarios**:

1. **Given** 「24 + 13」の文章問題、**When** 30 と答える、**Then** 「こたえは 37本」の下に「「あわせて」は たし算。しき: 24 + 13 = 37」が出る
2. **Given** 「26 ÷ 4」（あまりあり）、**When** 5 あまり 6 と答える、**Then** 考え方と「あまりは わる数の 4 より 小さく なるよ。もう 1つ ふやせるかも？」が出る
3. **Given** 「345 + 278」、**When** 513（くり上がりを足していない）と答える、**Then** 「くり上がりを わすれたかも？」が出る
4. **Given** どの問題でも、**When** 正解する、**Then** 解説は出ない
5. **Given** デイリーチャレンジ、**When** まちがえる、**Then** 同じように解説が出る

### Edge Cases

- よくある まちがいに当てはまらない答え → 考え方だけ出す
- 問題文が読めない形（古い問題など）→ 解説は出さず、今までどおり「こたえは ○○」だけ

## Requirements _(mandatory)_

- **FR-001**: 不正解のとき、回答の結果に「考え方」（文の並び）と「よくある まちがい」（無ければ空）を返さなければならない。正解のときは返さない
- **FR-002**: 文は explanations.md の形に従わなければならない
- **FR-003**: 問題・回答の判定・DB の形は変えない

## Success Criteria _(mandatory)_

- **SC-001**: 全問題（約2,300問）で考え方が作られ、その中の答えが正解と一致することを自動テストで確かめる
- **SC-002**: よくある まちがいの一言は、その まちがい方の答えのときだけ出ることを自動テストで確かめる
