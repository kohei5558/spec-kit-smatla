# まちがえたときの解説（案）

保護者の確認用。答えをまちがえたとき、「こたえは ○○」の下に出す。漢字は小3までに習うものだけ。
数字は例。実際は問題の数が入る。

```
✖ ざんねん…  こたえは 37本

💡 かんがえかた
「あわせて」は たし算だよ
しき: 24 + 13 = 37

🔍 くり上がりを わすれたかも？   ← よくある まちがいに 当てはまるときだけ
```

## たし算

| 問題 | かんがえかた |
|---|---|
| 1けた + 1けた（10をこえる） 8 + 5 | 8 は あと 2 で 10。5 を 2 と 3 に 分けて、10 と 3 で 13 |
| 1けた + 1けた（10をこえない）3 + 4 | 3 に 4 を たして 7 |
| 2けた以上 345 + 278 | 一の位から じゅんに たそう。くり上がりは 一の位と 十の位で 1回ずつ（上の位に 1 を たす） |

| よくある まちがい | 見分け方 | 出す言葉 |
|---|---|---|
| くり上がりを わすれた | 位ごとにたして、くり上がりを足さなかった数と同じ | くり上がりを わすれたかも？ |
| ひき算した | 子どもの答え ＝ 大きい数 − 小さい数 | ひき算に なっているかも？ たし算だよ |

## ひき算

| 問題 | かんがえかた |
|---|---|
| くり下がりあり（答え1けた）13 − 8 | 13 を 10 と 3 に 分けて、10 − 8 = 2、2 と 3 で 5 |
| くり下がりなし 7 − 3 | 7 から 3 を ひいて 4 |
| 2けた以上 623 − 278 | 一の位から じゅんに ひこう。ひけないときは 上の位から 1 かりて 10 に する。くり下がりは 一の位と 十の位で 1回ずつ |

| よくある まちがい | 見分け方 | 出す言葉 |
|---|---|---|
| くり下がりで 大きい方から ひいた | 位ごとに「大きい数字 − 小さい数字」をした数と同じ | くり下がりを わすれたかも？ ひけない 位は 上の位から 1 かりてね |
| たし算した | 子どもの答え ＝ たした数 | たし算に なっているかも？ ひき算だよ |

## かけ算

| 問題 | かんがえかた |
|---|---|
| 九九 7 × 8 | 7 の だん。7 が 8こ で 56 |
| 何十 × 1けた 30 × 4 | 3 × 4 = 12 の 10こ分 で 120 |
| 2けた・3けた × 1けた 23 × 4 | 23 を 20 と 3 に 分けて、20 × 4 = 80、3 × 4 = 12、あわせて 92 |
| 2けた × 2けた 23 × 45 | 45 を 40 と 5 に 分けて、23 × 40 = 920、23 × 5 = 115、あわせて 1035 |

| よくある まちがい | 見分け方 | 出す言葉 |
|---|---|---|
| となりの段と まちがえた | 答えが 正解 ± かける数（または かけられる数） | おしい！ 1つ となりの 九九かも？ |

## わり算

| 問題 | かんがえかた |
|---|---|
| 九九の逆 56 ÷ 7 | 7 の だんで 56 に なる 数を さがそう。7 × 8 = 56 だから 8 |
| 商が2けた以上 72 ÷ 3 | 72 を 60 と 12 に 分けて、60 ÷ 3 = 20、12 ÷ 3 = 4、あわせて 24 |

| よくある まちがい | 見分け方 | 出す言葉 |
|---|---|---|
| かけ算した | 子どもの答え ＝ かけた数 | かけ算に なっているかも？ わり算だよ |

## あまりのあるわり算

| 問題 | かんがえかた |
|---|---|
| 26 ÷ 4 | 4 の だんで 26 を こえない いちばん 大きい 数は 4 × 6 = 24。26 − 24 = 2 あまる。こたえは 6 あまり 2 |

| よくある まちがい | 見分け方 | 出す言葉 |
|---|---|---|
| あまりが わる数より大きい | 子どものあまり ≧ わる数 | あまりが 4 より 大きいよ。もう 1つ ふやせるかも？ |
| 商が1つ大きい | 子どもの商 ＝ 正しい商 + 1 | 4 × 7 = 28 は 26 を こえちゃうよ |

## 時こくと時間

| 問題 | かんがえかた |
|---|---|
| 2時間は 何分？ | 1時間 = 60分。2時間は 60 × 2 = 120分 |
| 1時間20分は 何分？ | 1時間 = 60分。60 + 20 = 80分 |
| 100分は 何時間何分？ | 60分 = 1時間。100分は 60分 と 40分 だから 1時間40分 |
| 1分30秒は 何秒？／90秒は 何分何秒？ | 1分 = 60秒。（上と同じ形） |
| 3時10分の 20分後（時をまたがない） | 10 + 20 = 30 で、3時30分 |
| 3時40分の 25分後（時をまたぐ） | 4時まで 20分。のこり 5分 すすめて 4時5分 |
| 4時5分の 15分前（時をまたぐ） | 4時まで 5分 もどる。のこり 10分 もどって 3時50分 |
| 2時40分の 1時間35分後 | まず 1時間 すすめて 3時40分。つぎに 35分 すすめる。4時まで 20分、のこり 15分 で 4時15分 |
| 2時10分から 2時45分までは 何分？ | 45 − 10 = 35分 |
| 9時50分から 10時30分までは 何分？ | 10時まで 10分、10時から 10時30分まで 30分、あわせて 40分 |

| よくある まちがい | 見分け方 | 出す言葉 |
|---|---|---|
| 分を 60 以上で書いた | 子どもの「分」（または「秒」）≧ 60 | 分は 60 より 小さく なるよ。60分で 1時間だね |
| 1時間 = 100分 と考えた | 時間と分のなおし方で、100分＝1時間として計算した数と同じ | 1時間は 100分 じゃなくて 60分 だよ |

## 長さ・重さ・かさ

| 問題 | かんがえかた |
|---|---|
| 3cm は 何mm？ | 1cm = 10mm。3cm は 10 × 3 = 30mm |
| 4cm5mm は 何mm？ | 1cm = 10mm。4cm は 40mm、5mm と あわせて 45mm |
| 45mm は 何cm何mm？ | 10mm = 1cm。45mm は 40mm と 5mm だから 4cm5mm |
| 1km300m + 800m は 何km何m？ | m どうしを たそう。300m + 800m = 1100m = 1km100m。1km と あわせて 2km100m |
| 2km − 400m は 何km何m？ | 2km を 1km と 1000m に 分けて、1000m − 400m = 600m。1km600m |

| よくある まちがい | 見分け方 | 出す言葉 |
|---|---|---|
| 倍率をまちがえた | 10倍・100倍・1000倍のほかの倍率で計算した数と同じ | 1km は 1000m だよ（その問題の単位の関係を出す） |
| 小さい単位が 大きすぎる | 子どもの小さい単位 ≧ 倍率 | m の ところは 1000 より 小さく なるよ |
