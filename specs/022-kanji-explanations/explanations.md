# 漢字の解説（2026-10-28 保護者確認済み）

保護者の確認用。漢字の問題（020）で まちがえたとき、「こたえは ○○」の下に出す文の **型**。
中身（字・読み・ことば）は、確認済みの [kanji-batch1.md](../020-kanji/kanji-batch1.md) から そのまま使う。新しく書く文は この型だけ。

```
✖ ざんねん…  こたえは えき

💡 かんがえかた
「駅」は「えき」と 読むよ
ことば: 駅員（えきいん）

🔍 ひらがなの ところ（い）は 入れないよ   ← よくある まちがいに 当てはまるときだけ
```

## かんがえかた

| 種類 | 型 | 例（駅・暑・球） |
|---|---|---|
| 読み | 「{問題の漢字}」は「{読み}」と 読むよ<br>ことば: {ことば}（{ことばの読み}） | 「駅」は「えき」と 読むよ<br>ことば: 駅員（えきいん） |
| 書き | 「{読み}」は「{漢字}」と 書くよ<br>ことば: {ことば}（{ことばの読み}） | 「えき」は「駅」と 書くよ<br>ことば: 駅員（えきいん） |
| ことば | 「{ことばの読み}」は「{ことば}」と 書くよ<br>「{漢字}」を つかう ことばだよ | 「えきいん」は「駅員」と 書くよ<br>「駅」を つかう ことばだよ |

- 「問題の漢字」は 読みの問題で [ ] の中の字。熟語のときは 熟語のまま（例: 「野球」は「やきゅう」と 読むよ）
- ことばの問題が無い字（寒・湖）は、「ことば:」の行を出さない
- 読みの「ことば:」は、その字の ことばの問題と同じ ことば（駅 → 駅員）

## よくある まちがい（当てはまるときだけ）

| 種類 | 見分け方 | 出す言葉 | 例 |
|---|---|---|---|
| 読み | 正しい読みに、[ ] のあとの ひらがな（送りがな）まで つけた | ひらがなの ところ（{つけた字}）は 入れないよ | 「[暑]い」に「あつい」→ ひらがなの ところ（い）は 入れないよ |
| ことば | 問題の字は あっていて、ほかの字が ちがう | 「{漢字}」は あってるよ。{何}つめの 字を よく 見てね | 「えきいん」に「駅貝」→「駅」は あってるよ。2つめの 字を よく 見てね |
| ことば | ほかの字は あっていて、問題の字が ちがう | {何}つめの 字が ちがうよ。「{漢字}」だよ | 「えきいん」に「馬員」→ 1つめの 字が ちがうよ。「駅」だよ |

- 書きの問題は、まちがえた字の形の説明が要るので、今回は 一言なし（考え方だけ）
- ことばの一言は、はじめ「「{読み}」の 字が ちがうよ」の案だったが、読みが送りがなの手前で切れる字（飲 →「の」）で変な文になるため、字の場所（1つめ・2つめ）で言う形にした（2026-10-28）
