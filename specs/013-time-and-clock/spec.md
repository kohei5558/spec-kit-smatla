# Feature Specification: 時こくと時間

**Feature Branch**: `feature/013-time-and-clock`
**Created**: 2026年10月26日
**Status**: Draft
**Input**: User description: "小3の単元『時こくと時間』を練習できるようにする（四則演算以外のカテゴリの1つ目）"

## 背景

問題は四則演算とあまりのあるわり算だけ。小3で習う「時こくと時間」（何分後・何分前の時刻、かかった時間、時間と分・分と秒の換算）は練習できない。
今後、長さ・重さの単位（014 予定）など四則演算以外のカテゴリを足していくため、その1つ目になる。

## Clarifications

### Session 2026-10-26

- Q: 出す問題の種類は？ → A: 何分後・何分前の時刻、かかった時間、時間と分の換算、分と秒の換算のすべて
- Q: 時刻に午前・午後をつけるか？ → A: つけない。「○時○分」だけで、12時をまたがない問題にする
- Q: 時計の絵を出すか？ → A: 出す（時刻が出てくる問題では、その時刻をアナログ時計の絵でも見せる）
- Q: デイリーチャレンジに出すか？ → A: 出さない（あまりのあるわり算と同じ扱い）

## 問題の種類と答え方

| 種類 | 例 | 答えの欄 | 時計の絵 |
|---|---|---|---|
| 何分後の時刻 | 3時40分の 25分後は 何時何分？ | [ ]時[ ]分 | はじめの時刻 |
| 何分前の時刻 | 4時5分の 25分前は 何時何分？ | [ ]時[ ]分 | はじめの時刻 |
| かかった時間 | 9時50分から 10時30分までは 何分？ | [ ]分 | 2つの時刻 |
| 時間→分 | 1時間20分は 何分？ | [ ]分 | なし |
| 分→時間と分 | 100分は 何時間何分？ | [ ]時間[ ]分 | なし |
| 分と秒→秒 | 1分30秒は 何秒？ | [ ]秒 | なし |
| 秒→分と秒 | 90秒は 何分何秒？ | [ ]分[ ]秒 | なし |
| 何時間何分後の時刻 | 2時40分の 1時間35分後は 何時何分？ | [ ]時[ ]分 | はじめの時刻 |

- 時刻は 1時〜11時台（0時・12時は出さない）。答えの時刻も 1時〜11時台に収まる（12時をまたがない）
- 「○時ちょうど」は「○時」と書く（「3時0分」とは書かない）。答えの「分」が 0 のときは 0 と入力する
- 文はやさしい日本語にする（「なんじなんぷん」などのふりがなは不要。数字と「時」「分」「秒」「何」は小3で読める）

## 難易度表（時こくと時間）

| 難易度 | 内容 | 例 |
|---|---|---|
| 1 | ○時間は何分？（ちょうどの時間、1〜3時間） | 2時間は 何分？ → 120 |
| 2 | 何分後の時刻（時をまたがない、5分きざみ） | 3時10分の 20分後は？ → 3時30分 |
| 3 | 何分前の時刻（時をまたがない、5分きざみ） | 5時50分の 15分前は？ → 5時35分 |
| 4 | かかった時間（同じ時の中、5分きざみ） | 2時10分から 2時45分までは？ → 35分 |
| 5 | 何分後・何分前の時刻（時をまたぐ、5分きざみ） | 3時40分の 25分後は？ → 4時5分 |
| 6 | かかった時間（時をまたぐ、60分未満、5分きざみ） | 9時50分から 10時30分までは？ → 40分 |
| 7 | 時間と分の換算（○時間○分は何分？／○分は何時間何分？、2時間59分まで） | 1時間20分は？ → 80、100分は？ → 1時間40分 |
| 8 | 何分後・何分前の時刻、かかった時間（1分きざみ、時をまたぐ） | 6時48分の 17分後は？ → 7時5分 |
| 9 | 分と秒の換算（○分○秒は何秒？／○秒は何分何秒？、2分59秒まで） | 1分30秒は？ → 90、90秒は？ → 1分30秒 |
| 10 | 何時間何分後・何時間何分前の時刻（5分きざみ） | 2時40分の 1時間35分後は？ → 4時15分 |

各難易度30問（組み合わせが30未満の難易度1は、ありうる問題すべて）。出題の難易度は「時こくと時間」の種類のレベルで決まり、学年に関係なくレベル1（難易度1〜2）から始まる（014 の種類ごとのレベル）。

## User Scenarios & Testing _(mandatory)_

### User Story 1 - 時こくと時間を選んで練習する (Priority: P1)

子供はホーム画面で「時こくと時間」を選び、時計の絵を見ながら、問題に合った欄（時・分、時間・分、分・秒、または1つ）に答える。全部の欄が合っていれば正解になる。

**Why this priority**: 本機能の目的そのもの。

**Independent Test**: 子供でログインし、「時こくと時間」を選んで問題を解き、全部の欄が合っているときだけ正解になることを確認する。

**Acceptance Scenarios**:

1. **Given** 子供がホーム画面を開いている、**When** 計算の種類を見る、**Then** 「時こくと時間」が6種類目として選べる
2. **Given** 「3時40分の 25分後は 何時何分？」の問題、**When** 問題画面を開く、**Then** 3時40分の時計の絵と、「時」「分」の2つの欄が表示される
3. **Given** 同じ問題で、**When** 4時・5分と答える、**Then** 正解になりポイントがもらえる
4. **Given** 同じ問題で、**When** 3時・65分 や 4時・15分と答える、**Then** 不正解になり「こたえは 4時5分」と表示される
5. **Given** 「9時50分から 10時30分までは 何分？」の問題、**When** 問題画面を開く、**Then** 2つの時刻の時計の絵と、「分」の欄1つが表示される
6. **Given** 「100分は 何時間何分？」の問題、**When** 問題画面を開く、**Then** 時計の絵は出ず、「時間」「分」の2つの欄が表示される
7. **Given** 計算の種類で「すべて」を選んだ、**When** 問題を解き続ける、**Then** 時こくと時間の問題も出ることがある
8. **Given** 他の計算（たし算など）の問題、**When** 問題画面を開く、**Then** 今までどおり（時計の絵は出ず、欄の形も変わらない）

---

### User Story 2 - 学習結果で別に集計される (Priority: P2)

学習結果画面と保護者の統計で、「時こくと時間」が他の種類と別に集計される。

**Why this priority**: 苦手な単元を見つけるため。US1 がないと意味がないため P2。

**Independent Test**: 時こくと時間を数問解き、学習結果の種類別の集計と学習記録の一覧を確認する。

**Acceptance Scenarios**:

1. **Given** 時こくと時間を解いた、**When** 学習結果画面を開く、**Then** 種類別の集計に「時こくと時間」が表示される
2. **Given** 学習記録の一覧で、**When** 時こくと時間の記録を見る、**Then** 子供の答えと正解が「4時5分」「1時間40分」「90秒」のように単位つきで表示される

### Edge Cases

- 欄を1つでも空欄のまま答える → 答えるボタンを押せない（あまりのあるわり算と同じ）
- 「分」の欄に 60 以上を入れる → 入力はできるが不正解になる（「4時5分」を「3時65分」とは答えない練習のため）
- デイリーチャレンジには、時こくと時間を選ばない
- 公開済みの DB にも、次の起動で問題が追加される（011 の `ProblemSynchronizer`）。既存の問題・学習記録は変わらない
- 新しい種類は計算の種類の**末尾**に足す（既存の問題セットを変えないため、CLAUDE.md）

## Requirements _(mandatory)_

### Functional Requirements

- **FR-001**: 計算の種類に「時こくと時間」を追加しなければならない
- **FR-002**: 問題は答えの形（1つ／時・分／時間・分／分・秒）を持ち、画面はそれに合わせて欄と単位を表示しなければならない
- **FR-003**: 時刻が出てくる問題は、その時刻（1つまたは2つ）を持ち、画面はアナログ時計の絵で表示しなければならない（正解は画面に送らない）
- **FR-004**: 回答 API は2つ目の答えを受け取り、2つの欄がある問題では両方が正しいときだけ正解としなければならない
- **FR-005**: 回答結果は正解を答えの形どおりに表示できる情報を返し、画面は不正解時に「こたえは 4時5分」のように表示しなければならない
- **FR-006**: 学習記録は子供が答えた2つ目の答えも保存し、一覧で単位つきで表示しなければならない
- **FR-007**: 問題は難易度表に従って作らなければならない（時刻は 1時〜11時台、12時をまたがない、分・秒は 0〜59）
- **FR-008**: デイリーチャレンジの問題には、時こくと時間を選んではならない
- **FR-009**: 計算の種類を表示するすべての画面（ホームの種類選択、問題画面、学習結果、学習記録一覧、保護者の統計）で「時こくと時間」を日本語で表示しなければならない

### Key Entities

- **CalculationType**: `Time = 5`（時こくと時間）を末尾に追加
- **Problem**: 答えの形と、時計に出す時刻を持つ（詳細は plan.md）。2つ目の答えは、あまりのあるわり算の `CorrectRemainder` と同じ仕組みを使う
- **LearningRecord**: 2つ目の答えは `StudentRemainder` と同じ仕組みを使う

## Success Criteria _(mandatory)_

### Measurable Outcomes

- **SC-001**: 子供は「時こくと時間」を選び、時計の絵を見ながら問題に合った欄に答えられる
- **SC-002**: 欄のどれか1つでも違えば必ず不正解になる
- **SC-003**: 時こくと時間の全問題が難易度表の条件を満たすこと（時刻の範囲、12時をまたがない、きざみ、正解が正しいこと）を自動テストで確認できる
- **SC-004**: 既存の計算の問題・学習記録・画面の表示は変わらない
